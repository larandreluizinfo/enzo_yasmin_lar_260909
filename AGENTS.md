# AGENTS.md

## Diretrizes de Atualização

- **Toda alteração** feita neste repositório deve ser **commitada** e **pushed** para o GitHub imediatamente.
- Não deixar alterações pendentes sem commit.
- Sempre fazer `git add .`, `git commit` com mensagem descritiva e `git push origin main` após cada modificação.
- Verificar o status do repositório (`git status`) antes e depois de cada tarefa.
- Mensagens de commit claras e descritivas em português.

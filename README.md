# Jogo do Grau 2P — enzo_yasmin_lar_260909

🏍️ Jogo do grau para 2 jogadores no mesmo teclado, com 8 motos diferentes.

Jogue aqui: https://larandreluizinfo.github.io/enzo_yasmin_lar_260909/

## Como jogar
- 🔵 P1: `W` acelera/empina, `S` freia
- 🟡 P2: `↑` acelera/empina, `↓` freia
- Mantenha o grau na zona verde (25°–70°) para turbo + pontos
- Passou de 85° = capotou!
- Corrida de 2000m — quem cruzar primeiro vence
- `R` reinicia, `Esc` volta ao menu

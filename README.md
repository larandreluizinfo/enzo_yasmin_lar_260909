# Super Enzo & Yasmin Bros 🍄

Jogo plataforma estilo Mario Bros com Enzo (Mario 🔴) e Yasmin (Luigi 🟢).

Jogue: https://larandreluizinfo.github.io/enzo_yasmin_lar_260909/

## Como jogar
- 1P: só Enzo | 2P: Enzo + Yasmin juntos
- 🔴 Enzo: `A/D` andar, `W` pular
- 🟡 Yasmin: `←/→` andar, `↑` pular
- Pegue 🪙, bata nos blocos `?` por baixo, pule na cabeça dos 👾, chegue na 🏁
